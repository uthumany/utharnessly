# CLI/TUI audit — 0.2.24 (2026-09-13)

Scope: the current Rust CLI, Ink TUI/setup wizard, npm/Python launchers, native installers, and release workflows. Physical-device and external-provider coverage must be reported separately; passing unit tests does not prove every feature works.

## Plan

1. Inventory CLI subcommands, TUI commands, setup stages, and installed dependencies.
2. Run existing Rust, UI, Python, package and installer checks.
3. Reproduce high-impact failures and add failing regressions before fixes.
4. Integrate @vr_patel/tui progress/badges with real counts and safe non-interactive output. Use requested terminal glyphs with fallbacks; pixel dimensions are controlled by the terminal font.
5. Exercise terminal interactions, resize, failures and cancellation; capture evidence.
6. Run final tests, commit scoped changes, publish native/npm/PyPI releases and verify registry versions.

## Fixed findings

- Selected provider/model are passed to backend requests; the model menu queries the native catalog. Late telemetry refreshes preserve the selection.
- Ctrl+C aborts the backend subprocess; cancellation is reported only after the subprocess returns.
- Supported slash commands invoke native functions; unknown commands fail locally. Multiword memory/skill queries are preserved.
- Menus have a bounded, scrolling viewport instead of clipping catalog entries. Text and Enter arriving in one input chunk now submit correctly.
- Timed, fabricated inference percentages were removed. The TUI and native chat now show a 15-stage local request pipeline; it reaches 0–100 only as observed lifecycle events occur and explicitly says remote token progress is not measurable.
- The npm launcher uses pinned `@vr_patel/tui` 1.0.0 for gradient progress with actual byte counts/ETA where the terminal is wide enough. Unknown lengths, redirected output, CI, NO_COLOR and unsuitable terminals do not animate. Downloads time out, remove partial files, and restore the cursor.
- TUI tool/setup and npm launcher status output use badges. Requested selector/agent/activity glyphs have ASCII alternatives. `NO_COLOR`, including an empty value, disables TUI theme colors.

Terminal glyphs occupy font-controlled character cells. A CLI cannot independently render a glyph at 48×48 pixels. Use a font with Egyptian Hieroglyph coverage or select ASCII icons.

## Remaining limitations and coverage boundaries

- Physical Windows/macOS/Android devices, terminal emulators, light themes and all font combinations were not exercised locally. Cross-platform CI is a separate gate, not proof of physical-device coverage.
- Background jobs and an interactive log browser are not implemented; the UI now says so. Some file/agent/memory overlays remain guidance, while slash commands expose native data.
- `/resume` lists sessions; use native `chat --session` for the existing session path. TUI autonomous prompts are not a persistent multi-turn conversation bound to `/new`.
- Agent inference has no real percentage or ETA. No artificial progress is presented as model completion.
- This progress integration is in the npm release downloader, not a Node dependency injected into curl/PowerShell installers.
- Status telemetry still has legacy defaults for context capacity and network state; it must not be treated as a measured token budget or connectivity probe.
- This is a tested set of fixes, not a claim that every advertised feature is implemented or bug-free.
